■ GanttApp Ver.1 — 起動方法

1. このフォルダをどこかに置く（デスクトップ等）
2. GanttApp.exe をダブルクリックで起動

■ フォルダ構成

GanttApp/
├── GanttApp.exe   ← これを起動
├── data/
│   └── default.json  （初期スケジュールデータ）
└── save/             （保存ファイルの置き場）

■ 使い方

・起動すると初期スケジュールが表示されます
・バーの端をドラッグ → 期間の変更
・バーをダブルクリック → 詳細編集
・バーを右クリック → ガスタービン交換・削除
・ファイル → 名前を付けて保存 → save フォルダに保存
・保存した .json ファイルはファイル → 開く で読み込めます

■ 注意

・GanttApp.exe 単体では動きません。フォルダごと移動してください。
・Python のインストールは不要です。
